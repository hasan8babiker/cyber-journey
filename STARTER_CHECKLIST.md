# Cyber Journey: Starter Checklist

**Approach:** courses and books for depth, projects for proof, CTFs for practice.
**Minimum on a bad day:** 30 minutes. That still counts.

---

## Rules

- [ ] One course and one book at a time. Finish before starting another.
- [ ] One active project at a time.
- [ ] Write up every CTF challenge solved, even in 5 lines.
- [ ] Push to this repo at least once a week.

---

## Weekly rhythm (flexible)

| What | Target |
|---|---|
| Course or book | A module or chapter on most days |
| CTF sessions | 2 to 3 per week |
| Project work | A few short sessions per week |
| Weekly check | One day: note what was finished, push to GitHub |
